# THE SHIFT · blunt blocks against a smooth curve

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **OCCUPATIONAL**.

An interactive rostering instrument: drag eight-hour shift blocks along a 24-hour clock, slide their length, switch the demand pattern (retail / office / overnight). Coverage vs demand, understaffed hours, and idle-paid hours are summed exactly — the gap between blunt shifts and a smooth demand curve. LIT arithmetic, AMBER the single-day model.
